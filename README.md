# angry-bird-python
# 🐦 Angry Birds Game in Python

A simple Angry Birds-style game built with Python and Pygame. This is my first project!

## Features
- Drag-and-launch slingshot controls
- Trajectory preview while aiming
- Pigs and destructible wooden blocks
- Collision detection and scoring
- 3 levels with win and game-over screens

## Controls
| Key / Action | What it does |
|---|---|
| Mouse drag + release | Pull back and launch the bird |
| R | Restart level |
| N | Next level (after winning) |
| ESC | Quit |
